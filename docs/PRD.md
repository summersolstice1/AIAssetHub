# 个人专属办公助手（AI & Asset Hub）- MVP 版本产品需求文档 (PRD)

## 1. 项目概述
这是一个供个人高频使用的桌面端效率助手，旨在管理 AI 资源、敏感凭证、本地环境及快捷启动本地软件。
*   **开发形态**：桌面端软件（推荐使用 Electron + Node.js 或 Tauri + Rust + 前端框架）。
*   **存储机制**：不使用大型数据库。所有用户配置、密码及资产数据均以加密或明文 JSON 文件形式（如 `config.json`）持久化存储在本地系统应用数据目录中。
*   **核心原则**：安全第一（数据不出本地）、体验轻量、高频操作一步到位（一键复制/一键唤醒）。

---

## 2. 系统整体技术要求
1.  **数据本地化**：所有增删改查直接面向本地 JSON 文件或通过桌面端 Store 插件实现。
2.  **安全性**：涉及“密码模块”及“API Key”的数据，存储时需在前端或通过本地代码进行轻量级加密（如 AES），防止 JSON 文件被直接意外读取。
3.  **系统权限**：需要有权限执行本地 Shell 命令（如执行 `python --version` 或拉起本地 `.exe`）。

---

## 3. 功能模块详细需求

### 🗺️ 模块一：AI 导航与凭证看板 (AI Dashboard)
*   **AI 应用区**：
    *   以卡片流（Card Grid）形式展示。点击卡片，调用系统默认浏览器打开对应的官网（如 ChatGPT, Claude 官网）。
*   **API Key 管理区（仿 CCSwitch 模式）**：
    *   表格视图（Table），包含字段：`平台名称` | `API Key` | `控制台网址`。
    *   **安全交互**：API Key 默认以掩码（`••••••••`）显示。点击右侧“复制”按钮直接将明文复制进系统剪贴板；点击“眼睛”图标可切换明文显示。
    *   点击“控制台网址”可直接跳转到对应的官方 Billing 或开发者后台。
*   **提示词（Prompt）分类仓库**：
    *   采用左侧分类菜单（Tab/Menu），右侧列表的联动结构。
    *   分类示例：`代码编写`、`文案润色`、`图像生成`。右侧列表每条记录展示标题和详细 Prompt 内容，并配有独立的“一键复制”按钮。

### 🖥️ 模块二：环境与监控看板 (System Hub)
*   **环境自动识别**：
    *   软件启动或点击刷新时，后端在后台执行 Shell 命令。
    *   **自动检测并展示**：
        1. 当前系统配置的 Python 版本（执行 `python --version` 或 `python3 --version`）。
        2. 本地 Conda 环境列表（执行 `conda env list` 并解析输出）。
        3. 检测是否存在 NVIDIA CUDA 驱动环境（检查 `nvidia-smi` 是否可用）。
*   **电脑资源监控**：
    *   **CPU & 内存**：每秒/每两秒定时刷新，以进度条或百分比数字展示当前占用率。
    *   **显卡资产 (GPU)**：通过调用系统底层命令（如解析 `nvidia-smi --query-gpu=...`）或相关库，实时抓取并展示 **NVIDIA GPU型号**、**显存 (VRAM) 已用/总共**（如: 4.2GB / 8.0GB）、**核心温度**。

### 🚀 模块三：开发软件快捷启动器 (DevLauncher)
*   **功能描述**：打破网页限制，让助手成为本地软件的统一入口。
*   **自定义配置**：用户点击“添加软件”按钮，输入软件名称，并填入（或通过文件选择器选择）本地软件的绝对路径（如 `C:\Program Files\Microsoft VS Code\Code.exe`）。
*   **一键唤醒**：主界面渲染对应软件的卡片。点击卡片后，后端调用系统进程命令（如 Node.js 的 `child_process.exec`），直接在系统后台拉起并运行该软件。

### 🔑 模块四：基础密码本看板 (SafeBox)
*   **功能描述**：纯本地化、分类存储个人各种敏感密码。
*   **分类管理**：通过 Tab 切换展示三大类：`软件账号`（如 GitHub）、`网页登录`（如各种论坛/云服务器）、`资产凭证`（银行卡号、开户行备忘）。
*   **数据字段**：每条记录包含 `名称`、`账号/卡号`、`密码`、`备注`。
*   **交互要求**：密码默认隐藏，配备“一键复制”和“显隐切换”按钮。

### 🔄 模块五：局域网两端互传 (Local Sync)
*   **功能描述**：不依赖公网服务器，解决手机与电脑端的数据同步。
*   **同步逻辑**：
    *   电脑端集成一个轻量级的 HTTP Server 模块（如 Express 或 Rust Http 服务），默认关闭。
    *   用户在电脑端点击“开启同步”按钮后，激活该本地服务器，并根据电脑的局域网 IP（如 `192.168.1.5:8080`）生成一个**二维码**。
    *   **手机端交互**：同一局域网下的手机扫码后，在手机浏览器中打开一个极简的网页。
        1. **下载**：点击可直接将电脑当前的 `config.json` 下载到手机。
        2. **上传**：支持在网页输入/粘贴新数据，点击同步后通过 `POST` 请求发送回电脑端，电脑端接收并追加更新本地的 `config.json`。
